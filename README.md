# どこでもダイヤモンド — Issue受付 / Diamond, anywhere — Issues

「どこでもダイヤモンド」(https://diamond.itachiwalker.com/)の、不具合の報告・要望を受け付けるリポジトリです。アプリのソースコードは置いていません。

This repository accepts bug reports and requests for **Diamond, anywhere** (https://diamond.itachiwalker.com/), an app that predicts when the sun or moon lines up with Mt. Fuji or any mountain or building ("Diamond Fuji", "Pearl Fuji"). The app's source code is not here.

## Issueの種類 / Issue types

- **不具合の報告 / Bug report** — 動作がおかしい、計算結果が違う / something doesn't work or the result looks wrong
- **建物・地域の追加の要望 / Building or area request** — 高層ビル・3Dモデルの追加、対応地域の拡大 / add a building, a 3D model, or an area
- **機能の要望 / Feature request** — 新しい機能や改善 / new features or improvements

[New issue](https://github.com/itachiwalker/diamond-anywhere-issues/issues/new/choose) から選んでください。日本語・英語のどちらでも書けます。

Choose one from [New issue](https://github.com/itachiwalker/diamond-anywhere-issues/issues/new/choose). You can write in Japanese or English.
